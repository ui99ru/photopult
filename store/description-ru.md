# Фотопульт — описание для RuStore (RU)

## Короткое описание (до ~80 символов)

Управляйте камерой одного телефона со второго. Без интернета и роутера.

## Полное описание

**Фотопульт** превращает два Android-телефона в камеру и пульт к ней. Поставьте один телефон
на штатив — он снимает; второй держите в руках — на нём живое превью, зум, спуск и таймер.
Идеально для групповых фото, где нужно попасть в кадр самому, для съёмки на расстоянии и
для стабильных кадров без касания камеры.

Связь работает **напрямую между телефонами** — без Wi-Fi роутера, без мобильного интернета,
без регистрации и аккаунтов. Телефоны находят друг друга по Bluetooth и соединяются по
быстрому Wi-Fi каналу (технология Google Nearby Connections).

**Что умеет:**

- 📷 Живое превью с камеры на пульте — видно кадр до съёмки
- 🔍 Зум и переключение фронтальной/основной камеры с пульта
- ⏱ Таймер 3 и 10 секунд с крупным отсчётом на обоих экранах
- 🔥 Серийная съёмка — удерживайте кнопку спуска
- ⚡ Управление вспышкой (выкл / авто / вкл)
- 🎯 Наведение фокуса касанием по превью
- ☀️ Коррекция экспозиции (ярче/темнее)
- 🔲 Сетка 3×3 для композиции
- 🖼 Готовое фото автоматически прилетает на пульт (полное качество — в галерее камеры)
- 🔋 Заряд батареи камеры виден на пульте
- 📞 Входящий звонок не прерывает сессию (работает в фоне)
- 🔁 Обрыв связи — автоматическое переподключение к запомненной паре

**Приватность прежде всего:** нет рекламы, нет встроенных покупок, нет аналитики и нет
запросов в интернет. Приложение ничего о вас не собирает и никуда не отправляет.

Работает офлайн где угодно: на природе, в дороге, на съёмке — везде, где есть два телефона.

## Ключевые слова

пульт для камеры, удалённая съёмка, дистанционный спуск, камера по bluetooth, селфи на штативе,
групповое фото, second phone camera, remote shutter, офлайн, без интернета
