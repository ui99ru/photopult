## Карточка приложения — краткая справка

- **Название:** Фотопульт
- **Категория:** Фото и видео
- **Возрастной рейтинг:** **0+** — нет пользовательского контента, чатов, рекламы, покупок,
  насилия и сбора данных. Приложение соединяет два телефона одного пользователя по прямому
  каналу и не выходит в сеть.
- **Монетизация:** нет (бесплатно, без встроенных покупок и рекламы).
- **Разрешения и зачем:**
  - Камера — сделать снимок;
  - Bluetooth / Wi-Fi (поиск устройств рядом) — найти второй телефон без интернета и роутера;
  - Местоположение (на Android ≤ 12) — этого требует система для поиска устройств по Wi-Fi/BT,
    координаты не используются;
  - Уведомления — показать, что сессия съёмки активна (foreground-service);
  - Хранилище (на Android ≤ 9) — сохранить фото в галерею.
- **Сеть:** приложение не обращается к интернету. Весь обмен — прямой канал между двумя
  телефонами (Google Nearby Connections).

## Иконка и графика

- Иконка приложения — адаптивная (`app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`),
  фон `#2166F3`, передний план — объектив с джойстиком и стрелками.
- Для витрины подготовьте иконку 512×512 (PNG) и скриншоты по чек-листу.
